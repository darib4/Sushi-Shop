A university web project developed as part of the Systems for e-Business course at the Faculty of Mathematics and Informatics (FMI).

The application allows users to browse sushi products, place orders, and complete online payments through Stripe integration. It also includes functionality for managing the order lifecycle, allowing orders to move through different processing stages.

The main goal of the project was to practice building a complete e-commerce workflow and working with web technologies, databases, and third-party payment services.

Developed with the assistance of AI coding tools for learning and productivity
